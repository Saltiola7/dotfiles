# Host tool maintenance Engineering Profile

Owner: dotfiles maintainer. Deliverable: internal chezmoi-managed host configuration.
Languages: Bash, Zsh, Go templates and Python tests. Supported scope: existing
macOS machine roles; Linux/guest behavior must remain unchanged unless explicitly
included in a later slice. No new product UI or public service is introduced.

Compatibility: preserve managed target paths, user credentials and histories,
external-state routing, Python minor pins, project dependency constraints and
guarded AI launchers. Package updates require consumer classification; production
environments and enterprise-seo-tools are excluded. Guest work is deferred.

Trust boundaries: shell environment selects executables; chezmoi source must not
overwrite unrelated user work or copy credentials into tests. Existing native
installers own binaries. Local fixtures use isolated HOME and no cloud credentials.

Authorities: pytest configured in pyproject.toml, affected shell syntax checks,
chezmoi rendering/diff and targeted apply, executable-resolution probes. Existing
terminal and AI ownership tests remain required for shared shell changes.

Lifecycle: kernel and Review/Integrate required; Deploy, Operate and Maintain/Retire
required for managed shell deployment. Release not applicable: no package or
versioned executable is published. Normal feature-branch draft PR into main;
preserve dirty primary checkout and reconcile only owned hunks after delivery.
