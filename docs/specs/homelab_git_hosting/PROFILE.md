# Engineering Profile

Owner-operated private Git hosting on Fedora ARM64 Raspberry Pi 400. Native
Forgejo 15 LTS, SQLite and systemd; maintained Python 3.12+ provisioning and
standard-library checks. Python, Cloud and Security modules apply; elevated risk.
Chezmoi owns declaration, while runtime database, repositories, host SSH keys,
admin credentials, tokens and endpoint bindings remain private. Existing shares,
object storage, backups and administration access must be preserved.

Kernel, review/integrate, deployment, operation and maintenance gates required.
Release not applicable: no package published. Authorities: scoped pytest,
signature/checksum validation, systemd/resource checks, denied access, isolated
Git clone/push/clone byte comparison, stopped SQLite/file Borg capture/restore,
and fresh startup. No CI runners, workload migration or production guarantee.
