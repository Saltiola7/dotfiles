# Homelab Topology Engineering Profile

Owner: personal dotfiles maintainer/operator. Internal infrastructure deliverable;
no synthetic Product Intent artifact is required. Home repository: dotfiles.
Applicable modules: Cloud/Platform/IaC and Security; Python module when Python
implementation is selected. Existing personal and AI target ownership must remain
separate. Public documentation must not contain credentials or private connection
inventory. History and node credentials are never provisioning source.

Authorities: configured pytest (Python 3.12–3.14), focused schema/behavior tests,
chezmoi target/rendering checks for managed files, source review and live read-only
observations. A missing required capability stays unavailable, not passed.

Runtime: macOS administration entry point and private read-only observation
adapters. Inventory covers physical machines, VM/container targets and storage.
Interfaces: stable target IDs and hosting/access/dependency edges; diagram and
text/table output must agree. Connection bindings are a separately classified
local overlay. Declarations do not impersonate live discovery.

IaC authority: reviewed versioned target declarations. Runtime probes are evidence
and can report drift; they never silently overwrite desired state. The operator
owns updates, backups, access and retirement decisions. Observation failure marks
unknown/stale and must not remove a target. Cost is bounded by using existing
resources; no purchases or paid infrastructure are authorized.

Risk: elevated due to private infrastructure metadata and operational targeting.
Kernel and Review/Integrate required. Release not applicable: no package or hosted
service is published. Deploy applies when installing the inventory CLI/config.
Operate and Maintain/Retire apply to a long-lived inventory: freshness, support,
retention and access-revocation procedures are required.
